# Portfolio de Jean-Louis KORANGUI

Site vitrine statique en HTML, CSS et JavaScript. Il fonctionne sans framework et peut être publié gratuitement avec GitHub Pages.

## Avant publication

1. Remplacez `assets/portrait-placeholder.txt` par votre vraie photo, enregistrée sous `assets/portrait.jpg`.
2. Ajoutez votre CV PDF sous `assets/CV-Jean-Louis-KORANGUI.pdf`.
3. Vérifiez l'adresse e-mail et ajoutez l'URL exacte de votre profil LinkedIn.
4. Complétez les dates, établissements, intitulés de postes et missions.
5. Remplacez les cartes de projets fictives/de démonstration par vos réalisations réelles. Elles sont explicitement présentées comme des emplacements à compléter et ne doivent pas être revendiquées comme des projets terminés.
6. Vérifiez chaque compétence et supprimez celles que vous ne maîtrisez pas encore.

## Ajouter votre photo

Utilisez une photo professionnelle, cadrée de la tête au haut du torse, avec un fond simple. Renommez le fichier `portrait.jpg` et placez-le dans `assets/`. Le site l'affichera automatiquement.

## Publier gratuitement avec GitHub Pages

1. Connectez-vous à https://github.com/.
2. Créez un nouveau dépôt public nommé `portfolio-jean-louis-korangui`.
3. Décompressez cette archive sur votre ordinateur.
4. Importez à la racine du dépôt les fichiers `index.html`, `style.css`, `script.js`, `README.md` et le dossier `assets`.
5. Dans le dépôt, ouvrez **Settings > Pages**.
6. Dans **Build and deployment**, choisissez **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`. Enregistrez.
7. Attendez la fin du déploiement. Votre site sera disponible à l'adresse :
   `https://VOTRE-PSEUDO.github.io/portfolio-jean-louis-korangui/`

## Structure

- `index.html` : contenu du portfolio.
- `style.css` : design responsive noir et doré.
- `script.js` : menu mobile et année automatique.
- `assets/` : photo et CV à ajouter.

## À savoir

Le formulaire de contact n'est pas utilisé : le bouton e-mail ouvre directement le logiciel de messagerie du visiteur. Aucun service externe ni base de données n'est nécessaire.
